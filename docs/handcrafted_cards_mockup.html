DVI-I vs DVI-D (Exam Trap!)
*4 pins around blade = ANALOG (VGA compatible)*

• DVI-I = Integrated (carries Digital + Analog).

• DVI-D = Digital ONLY (has 4 pins NO! NO PINS AROUND BLADE!).

• DVI-A = Analog only (rare, 12+5 pins).

• Dual-link max resolution: 2560 × 1600 @ 60Hz.

Exam Passport Rule: If question mentions connecting an old VGA CRT monitor via a passive adapter, the answer MUST be DVI-I. DVI-D cannot do analog!

// FIELD FAILURE MODE: ANALOG SHADOWING

SYMPTOM: User connects older CRT scale monitor to PC using a cheap passive DVI-to-VGA adapter block. Screen shows ghosting trails and flickering lines.

ROOT CAUSE: The passive adapter uses pins C1-C4 of DVI-I. If the video card only implements DVI-D, no analog voltage is driven. If unshielded, 60Hz plant machinery couples into the high-impedance RGB lines.

DVI: The Four Analog Pins RED BAND #14
"Look for the cross around the blade!"

⚡ DVI-I has 24 digital pins + 4 analog pins around the blade.

⚡ DVI-D is missing those 4 pins. It cannot output VGA signal.

⚡ Dual-link gives you 2560 × 1600. Single link caps at 1920 × 1200.

Exam Trick: Passive VGA adapter will physically NOT FIT into a DVI-D port because the blade slot has no pin holes!

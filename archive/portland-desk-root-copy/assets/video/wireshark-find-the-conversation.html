  • 1A span port is a switch port that gets a copy of the traffic passing through.
  • 2Everything on the wire lands in the file: name lookups, pings, log messages, and Jared's session.
  • 3Your job: pull the one conversation you need out of the rest.
Open the file in Wireshark with File → Open, or drag it onto the window.
STEP 1Read the Protocol column
  • 1Each row is one packet, in the order it arrived.
  • 2The Protocol column says what kind of traffic it is: ARP, DNS, ICMP, NTP, Syslog…
  • 3The Info column gives a one-line summary.
With 137 packets mixed together, scrolling isn't the way to find one conversation.
STEP 2Filter by protocol name
  • 1Type the protocol name in lowercase in the filter bar.
  • 2Press Enter. Only that protocol's packets stay on screen.
137 packets in the file
Showing: 137
Example: dns shows only the name lookups. The other packets are hidden, not deleted.
STEP 3Filter by port
  • 1A port number says which service the traffic belongs to.
  • 2udp.port == 514 keeps UDP packets to or from port 514, which is where syslog (log messages) travels.
  • 3Use tcp.port the same way for TCP traffic.
Here the switch is sending its log messages to a log server.
STEP 4Hide the noise with not
  • 1not (or !) hides a protocol.
  • 2Join several with and to hide more than one kind. Here the ARP and ping packets are gone.
137 packets in the file
Showing: 137
Hide what you know you don't need until what's left is small enough to read.

Follow UDP Stream (syslog from the switch)
Right-click a packet → Follow → the stream type. The whole conversation opens as readable text, in the order it happened. Red is client to server; blue is server to client.
Following a stream also sets a display filter. Click Back to restore the filter you had.
NO GUI?The same filter at the command line
  • 1-r names the capture file. -Y takes a display filter, the same kind you typed in Wireshark.
  • 2Same filter, same packets. These are the first three of the 30 syslog messages.
No screen to click on? tshark -Y does the filtering for you.
